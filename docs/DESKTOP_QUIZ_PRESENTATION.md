# 桌面端双呈现设计

> 2026-10-15：工作区实现，随 v0.2.0 交付；不作为已发布 v0.1.6 的能力。

## 1. 范围与原则

采用“一套答题内核、两种呈现”，不创建第二套题库、判分或错题系统。

界面名称统一为“滚动”和“传统”：滚动对应连续滚动，传统对应一题一页。仅修改展示名称，内部 `continuous` / `single` 标识及已有偏好数据不变。

- 连续滚动为默认，保留现有按题号排列与窗口化渲染。
- 传统只挂载当前题，页面采用左侧答题卡、右侧题目框的全高桌面布局；长题干、图片、代码、场景和全部子题可在右侧题目框内自然滚动，不限制为一屏。
- 仅在设置 → 偏好设置中提供“滚动 / 传统”滑块，选中项加粗并支持键盘聚焦。答题页只显示当前题号，不重复暴露呈现切换按钮；用户从设置返回后，下一次进入答题页使用新偏好。
- 偏好写入 `localStorage.desktopQuizPresentation`。未知值或读取失败回退连续滚动；写入失败保留本次选择并提示未保存。
- Windows 桌面布局和宽屏 Web 生效；Android 与移动 Web 保持原有单题界面，不展示或读取这个开关。
- 考试结束后的回顾页暂不纳入双呈现。

## 2. 当前题与阅读位置

连续滚动时，以视口上方约 20% 的阅读线为基准（至少 96px，并避开固定工具栏），取题目顶部已越过阅读线的最后一题；长题滚到中部仍属于当前题，不按“距离哪个题顶部最近”提前跳下一题。

切换流程：

1. 在 DOM 改变前记录当前题及其顶部的视口偏移。
2. 切换渲染方式，不清空答案、不判分、不重新初始化 session。
3. DOM 更新后将同一道题对齐至目标呈现上次记录的阅读偏移；首次切换沿用来源偏移。
4. 浏览器布局与滚动锚定稳定后再校正一次，期间暂停滚动追踪，避免把当前位置误判为另一题。

两种呈现的阅读偏移按题目分别记录，仅存在本次桌面视图内存中；切换题库或题目顺序后清空。重启恢复呈现偏好及现有可持久化模式的题目/答案，不承诺恢复精确像素位置。

只有传统模式显示“上一题 / 下一题”底部导航，首题禁用上一题，末题禁用下一题；空列表不显示题目导航。滚动模式不显示这两个按钮或底部导航栏，通过滚动和答题卡跳转浏览；考试提交按钮独立保留。答题卡和传统模式翻页共用跳转入口，显式跳转对齐题目顶部。连续滚动扩大渲染窗口时保留当前阅读锚点，减少占位符高度变化造成的跳动。

传统模式进入时，答题卡始终展开并固定在左侧，不提供收起或取消固定操作；题目框占据右侧并包围整个传统模式内容。呈现偏好从设置修改后，仅重建答题卡的抽屉状态，不重置答题 session；同一呈现下翻页和作答保持布局。滚动模式保持原来的可展开/收起行为；考试回顾页保持原来的展开且固定。

## 3. 状态与组件边界

| 入口 | 职责 |
| --- | --- |
| `useQuiz.ts` | 题目顺序、当前索引、答案、复合题草稿、判分、进度与错题业务；跳转只修改 session 状态 |
| `useQuizPresentation.ts` | 桌面呈现偏好与保存失败提示 |
| `useDesktopQuizViewport.ts` | 滚动追踪、阅读锚点、切换/跳转对齐及卸载清理 |
| `QuizSessionView.vue` | 单题或连续列表，复用相同 `QuestionDisplay`、答题卡与工具栏 |
| `QuizPresentationSwitch.vue` | 设置页的滚动 / 传统开关 |
| `CompoundQuestion.vue` | 受控子题输入；草稿来自 session，输入事件回传内核 |

复合题增加可选 `AnswerSheetEntry.subDrafts: Record<number, string>`，与已判分的 `subAnswers` 分开。输入不意味着提交或锁定，提交一个子题不清掉其他子题草稿；组件卸载、窗口化和分页后可恢复输入。旧 session 没有该字段仍兼容。考试提交时由原判分入口处理尚未提交的草稿。

移动端只接入共享复合题草稿事件，不改变移动端布局。普通单题、多选和多空填空继续由原 `modelValue` 控制，避免组件内状态成为唯一数据源。

## 4. 模式规则

| 做题模式 | 双呈现行为 |
| --- | --- |
| 练习 / 专项 | 保持原自动/手动提交规则和按题库保存的进度 |
| 考试 | 翻页与切换不提交试卷；提交入口保留，考试结果仍进入原回顾页 |
| 背题 | 保持只读与答案展示，切换不生成答题记录 |
| 错题 | 保持错题移除、清空答案、导出与当前错题本规则 |

当前实现没有独立考试计时器；本次不引入计时或新的考试恢复规则。

## 5. 验证与发布边界

自动化测试：`node --test scripts/test-quiz-presentation.mjs`，纳入 `npm test`。

覆盖偏好默认值、损坏值、存储失败、跳转边界、共享答案与结果、复合题草稿序列化与恢复、部分提交、考试草稿判分、组件重挂载，以及阅读位置切换和连续快速跳转。

Edge 无头浏览器使用内存拦截的合成题库回归，不写入真实用户题库：设置开关、五种做题模式、上一题/下一题、答题卡、滚动追踪、图片长题阅读位置、复合题草稿与已提交结果、刷新恢复、窄桌面及移动端隔离。

发布前仍需 Windows 安装版人工验收：真实含 Markdown、公式、图片、代码和复合题的题库；快速切换、图片/图表异步加载、错题移除、重置、异常退出和重启。不因工作区浏览器测试通过而替代 v0.2 安装版验收。
