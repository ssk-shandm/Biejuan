## 文档维护约定

- 当前实现以代码和最近发布版本为准；历史诊断文档只用于解释背景和迁移原因。
- 数据目录、配置格式、题库格式、发布流程或安全策略发生变化时，应同步更新相关文档。
- 个人题库、图片、错题本、API Key、临时脚本、构建目录和签名材料不放入 `docs/` 或 Git。
- 版本路线中的 `0.x.0` 是功能里程碑；`0.x.y` 只用于 Bug、回归、兼容性和安全修复。
