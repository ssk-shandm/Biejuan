# v0.2.1 发行说明

日期：2026-10-20。状态：补丁版本已完成构建及自动化验证，已发布 [GitHub Release](https://github.com/ssk-shandm/Biejuan/releases/tag/v0.2.1)；Windows 实际安装、覆盖升级和卸载验收尚未执行。

## 用户可见变化

### 1. 新手指引回归简洁，切换更连贯

新增首次使用指引，也可从“设置 → 新手教程”重新查看。先介绍主页和自上而下的五种学习模式，再讲解设置、偏好、文档转换、AI 模型配置、题库资源、导入、批量删除、全量备份和运行终端。

提示卡延续应用的极简风格，仅在目标外使用轻遮罩；无目标的说明不压暗页面。切换步骤先测量下一张卡片，位置、宽高、高亮蓝框与遮罩开孔使用同一动画进度，避免闪回第一步、尺寸突然跳变及高亮跟随滞后。

### 2. 不会配置 AI，也能导出 Prompt 手动转换

“设置 → AI 模型配置”新增“导出 Prompt”。无需填写模型地址或密钥，将提示词和资料交给能够读取文件的聊天 AI，生成完整题库 JSON 后，在“题库资源 → 导入 JSON 题库”校验、预览并确认导入。

导出的提示词独立于应用内转换流水线，包含最终数组 Schema 和格式示例，不包含连接配置、API Key 或用户资料。明确说明手动流程没有应用内的自动分段、流式接收、续接和校验修复；聊天窗口逐字显示不代表没有上下文或输出长度限制。

### 3. 提高复杂文档转换的通用兼容性

结构分析与转换提示词加强来源、章节、材料组、原题号及题干特征的关联，处理题目重述、不同章节同号、PDF 提取顺序错乱、跨页答案和解析。参考范文、参考译文不再一律留空，阅读文章、共享词库和段落选项保留作答所需材料；题型按实际作答方式判断，不绑定具体考试或样本文档。

修复已有行内答案的题目跳过独立解析匹配的问题：现在分别补齐答案和解析，支持仅返回解析，不覆盖已有答案，也不虚增补答案数量。转换失败及图片关联日志补充定位信息，便于发现漏题和未关联资源。

### 4. 排错记录可以打包保存

运行终端支持将当前最多 300 条日志导出为 ZIP，包含纯文本、结构化 JSON 和说明。收集时对常见凭据脱敏，修复 Error 堆栈未走脱敏的问题；分享前仍需检查题干、路径和其他不希望公开的资料。桌面导出使用原生文件保存对话框，支持取消和失败反馈。

### 5. 版本与更新入口保持一致

应用版本统一为 0.2.1，更新检查和项目链接指向现有 `ssk-shandm/Biejuan` 仓库。沿用应用标识、用户数据目录、v1 错题本格式及 v0.2 数据版本，不更改已有题库或学习记录。

## 兼容性与边界

- 本次仅发布 Windows x64 NSIS 安装程序，不发布便携版 EXE 或 Android APK；应用内更新使用安装包。
- 安装包未签名，Windows 可能提示未知发布者。覆盖安装前建议导出全量备份，卸载时不要选择删除应用数据。
- 提示词不能替代模型的文件读取、OCR、上下文和推理能力；未通过真实模型完成整份复杂 PDF 的转换评测，不承诺所有文档都能无遗漏转换。
- 长资料建议按“完整题目＋必要材料＋对应答案解析”分批，核对漏题、参考答案及解析后再导入。JSON 格式校验通过不等于内容完整正确。
- 日志脱敏不等于清除了全部个人信息；模型配置、私人题库、图片及错题数据不作为发行资产上传。
- 自动化与浏览器验收不代替真实 Windows 安装、覆盖升级或卸载验收；本次未对用户真实数据执行安装操作。
