## 4. 数据保护约定与未解决限制

- 保持现有 `com.exam.assistant` 应用标识、原生 `quiz-data.json`、浏览器 `wrongNotebookData_v2` 和 v1 错题备份结构，不在补丁版强制切换数据模型。
- 损坏/无权限数据先保存原始文件或浏览器键，再显式恢复有效备份；保护状态下的临时操作不会覆盖被保护的原件，不应当作可靠保存。
- 恢复成功表示备份校验通过且浏览器副本已提交；原生文件仍异步保存，失败会另行提示。
- 浏览器副本只是在同一设备、同一 WebView 存储仍可用时的后备，不是独立快照，也不是云同步。
- 本次未实现原子文件替换、自动备份、全量备份、统一 schemaVersion/迁移框架；原生写入中断导致的半个 JSON 风险仍需 v0.2 解决。
- 默认模板只用于新建配置；不会覆盖用户现有 `llm-config.txt`。开发版仍读写 `config/llm-config.json`，不要提交真实密钥。

## 5. v0.2 第一批工作（按顺序）

1. **数据盘点**：题库、图片、错题本、练习会话、设置和 AI 配置的后端、格式、读写位置、错误行为。

4. **导入与刷题回归**：明确答案/题型校验、无效题库报告、全部题型判题、进度恢复与跨题库清理。
5. **真实安装环境**：升级/卸载/重装、普通权限、更新失败及恢复演练。
