# 别卷 v0.1.3

发布日期：2026-09-30。

- AI 文档转换改为多步流水线：模型先分析文档结构（题目区 / 答案区）并命名题库，再分段并发转换、回填独立答案区，逐题 Schema 校验与自动修复。
- 新增 PowerPoint `.pptx` 导入；Word 文档支持还原自动编号、表格与内嵌图片，图片自动关联到对应题目。
- 模型请求支持流式读取、空闲超时、429/5xx 退避重试、JSON 模式与推理开关自动降级，并可随时取消转换。
- 修复 Android 端开始转换后跳转终端页导致转换被中止、返回后结果丢失的问题。
- 修复 Android 系统文件选择器中 Markdown、XLSM 等格式无法选择的问题。
- 修复 Android 端部分页面文字乱码。

下载选项：Windows x64 安装程序、Windows x64 便携式 EXE、Android arm64（arm64-v8a）已签名 APK。Android 正式版与 v0.1.2 使用同一发布证书，可直接覆盖安装。Android 正式版仅允许 HTTPS 模型地址；转换较长文档时请保持应用在前台。
