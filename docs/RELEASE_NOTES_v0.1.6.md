# 别卷 v0.1.6

发布日期：2026-10-06。

- 修复旧版错题迁移在存储空间不足或 JSON 损坏时丢失原始数据的问题，迁移先完整校验并一次性提交，失败时保留原始数据。
- 修复启动时错题数据尚未读取完成就允许操作的问题，桌面和移动布局先完成持久化加载，再开放页面操作。
- 修复错题保存的时序问题：浏览器副本及时保存，原生文件串行写入；两端均有时间戳时可恢复更新的浏览器副本，写入失败会提示并允许后续重试。
- 损坏或无法读取的错题数据不再被自动覆盖；恢复备份前校验字段、重复 ID 和跨题库引用，兼容 UTF-8 BOM 与旧版可选字段，恢复失败不改变当前数据。
- 修复从已有数据加载后新错题记录 ID 可能冲突的问题，保持现有应用标识和 v1 错题备份格式兼容。
- 桌面默认 AI 配置改用无密钥的公共模板，不再将可写的开发配置编译进安装包；已有用户配置不会被重置。
- 补齐错题持久化、恢复保护、版本一致性和发布资源回归检查，并整理 v0.1 收尾清单及 v0.2 路线 TODO。

下载选项：Windows x64 安装程序。本版本不发布便携版 EXE 或 Android APK；自动更新功能需要使用安装版。

验证情况：配置、ESLint、TypeScript、32 项 JavaScript 测试、7 项 Rust 测试、Web 生产构建、发布资源检查和 Windows NSIS 构建均通过；另完成隔离合成题库的桌面/移动布局浏览器冒烟验证。Windows 安装、覆盖升级、卸载和 Android 真机人工验收尚未完成。

使用提醒：覆盖安装前建议导出错题本备份。现有备份只包含错题本相关数据，不包含题库、图片、练习进度和 AI 配置；原子写入、自动快照及全量备份恢复仍属于 v0.2 计划。
