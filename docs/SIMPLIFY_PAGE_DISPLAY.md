# 简化页面显示

本文用于后续新版本的更新描述，不绑定具体版本号。

## 错题本练习

- 新增“添加到新的错题本”：在错题本练习中，将本轮再次答错的题目收集到一个独立的新错题本；综合题有已判错的子题时，收录整道题。
- 新错题本保留完整的错题本逻辑，可继续练习、移除题目、重命名、导出，并可将再次答错的题目继续收集到下一份新错题本。
- 原错题本的题目与答题记录保持不变，创建后仍停留在原本练习；返回错题本列表即可找到新本。同本内重复出现的题目只收录一次，没有再次答错的题目时不会创建空本。
- 错题练习进度按错题本分别保存，避免新本沿用旧本的答案；旧版按题库保存的进度会迁移到升级后首次打开的错题本。

## 页面精简

- 移除错题本页面的“备份全部错题本数据”“恢复全部错题本数据”入口，以及桌面端底部重复的超大“开始练习”按钮。保留各错题本卡片上的练习入口及原有错题导入、导出功能。
- 移除设置页顶部“本地数据已就绪”状态文案及左侧绿色圆点。
- 移除设置左侧栏中的“可用题库”“当前题库”两个显示块。
- 文档转换页面不再显示模型名称和服务地址，并移除“模型尚未配置”整块提示（含说明及“去配置”按钮）；开始转换时仍校验模型连接配置。
- AI 模型配置页面移除“提示词与结构已就绪”状态提示；保留连接配置、测试及加载失败提示。
- 桌面做题呈现滑块两侧不再显示“滚动”“传统”，改为切换后在右上角提示当前模式。

## 发布描述短版

简化页面显示：精简设置页和错题本页面的重复信息与操作入口，隐藏文档转换页的模型名称和服务地址。错题练习新增“添加到新的错题本”，可将再次答错的题目独立收集、分轮复习，并为每个错题本分别保存练习进度。
