# Markdown、公式与学习工具

更新时间：2026-10-15。本文描述 v0.2.0 工作区能力；不是 2026-10-06 的 v0.1.6 发行说明。

题干、选项、参考答案、可接受答案、解析、材料和综合题小问统一通过 Markdown 渲染。未指定格式时默认 `markdown`；旧题库的 `text`/`txt` 字段无需手动迁移，也会使用统一的展示组件。纯 Mermaid / PlantUML 图表仍保留各自格式，程序代码应放入带语言标记的代码围栏，避免被识别为公式或 Markdown。

## 公式和图片

- 行内公式：`$x^{2}$`、`$\frac{1}{2}$`、`$\sqrt{a+b}$`。
- 独立公式：将 `$$...$$` 放在独立行，也支持 `\(...\)` 和 `\[...\]`。
- 旧内容中的简单幂表达式（如 `x^2`、`2^{10}`）也能直接显示上标；代码块和行内代码不受影响。
- 图片语法：`![题目配图](path/to/image.png)`，原有 `images` 数组仍可使用。Markdown 图片按容器宽度等比显示；外部地址的图片仍需联网。
- JSON 内的 LaTeX 反斜杠需转义，例如 `"answer": "$\\frac{1}{2}$"`。

AI 转换、独立答案区匹配和校验修复提示词都要求识别平方、幂、上下标、分数等数学内容，保留原意并输出 Markdown + LaTeX，不自行解题。公式已在原文件抽取或 OCR 阶段丢失的旧题库，需要核对原文或重新转换，渲染器无法恢复缺失信息。

填空答案比对会忽略公式定界符，并将数字幂的 `{}` 和 Unicode 上标规范化，例如 `$x^{2}$`、`x^2`、`x²` 可按相同文本比对。这不等同于代数等价判定，分式、化简等仍需在 `answerDetail.accepts` 中提供可接受写法。

## 其他交互
- 单题“添加到错题”直接保存并显示“已在错题本”，不再弹出成功提示。保存失败、删除和批量操作原有提示仍保留。
- 单题“复制题目”复用同组操作按钮样式，默认只显示文字；复制中显示旋转图标，成功显示“已复制”和勾选动画，失败显示可重试提示，均在按钮内反馈，不弹窗。
- 成功反馈 2 秒后恢复，失败反馈 3 秒后恢复；切换题目清除旧反馈，支持系统减少动态效果设置。
