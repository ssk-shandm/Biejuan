# 别卷 v0.1.2

发布日期：2026-09-28。

- 增加 Android 手机适配：独立移动端页面、底部导航与返回处理，首页及错题本统一移动端布局。
- Android 图标与 Windows 桌面端统一，覆盖普通、圆形与自适应图标。
- 完善 AI 文档转题库、导入导出、题库持久化与桌面更新提示。
- 项目文档统一移入 `docs/`，更新构建及发布说明。

下载选项：Windows x64 安装程序、Windows x64 便携式 EXE、Android arm64（arm64-v8a）已签名 APK。Android 数据与桌面端数据不会自动同步，升级前建议备份个人题库和错题本。首次 Android 正式版使用独立发布证书签名；若此前安装了调试版（不同签名），Android 可能要求先卸载调试版，卸载前请备份应用数据。
