## 更新摘要
- 新增国内加速下载：更新包优先从公共镜像下载，镜像不可用时自动回退 GitHub 官方地址，无需用户自行配置代理。

## 详细更新
本次为 v0.2.4 补丁版本，日期：2026-10-22。构建与发布状态见本版本 GitHub Release。

### 更新下载加速
- 此前更新安装包直接从 GitHub Releases 下载，中国大陆网络经常超时或无法连接，普通用户也不会为此单独配置代理，导致自动更新实际不可用。
- 现在下载地址按顺序尝试：先拼接国内镜像前缀（当前配置 `https://gh-proxy.com`、`https://ghfast.top`），全部失败后再回退 GitHub 官方地址，用户无需任何额外操作。
- 镜像顺序按 2026-10-22 实测确定：`ghfast.top` 当时请求超时，`gh-proxy.com` 正常返回 200 且文件大小一致，因此把可用镜像放在首位，减少等待首个镜像超时的时间。
- 前端新增 `src/utils/downloadSource.ts` 负责候选地址构建：只有 GitHub 资源地址才会被加速，非 GitHub 地址和空前缀原样返回；官方地址始终保留在候选列表末尾作为兜底。
- 下载过程逐个尝试候选源，任一成功即停止；切换下载源时写入运行终端日志，便于排查。
- 更新弹窗新增说明文字，告知用户已自动使用国内加速、无需代理。

### 原生下载地址校验
- Rust 端 `validate_update_url` 增加镜像域名白名单（`ghfast.top`、`gh-proxy.com`、`ghproxy.net`），但未放宽安全性：镜像地址后必须内嵌一个完整的 `https://` GitHub 资源地址，且内嵌主机同样必须在官方资源域名白名单内，否则拒绝下载。
- 新增 Rust 单元测试覆盖：官方地址放行、镜像前缀放行、非 HTTPS / 未授权主机 / 镜像后非 GitHub 地址 / 镜像后缺少内嵌地址等畸形地址拒绝。

## 安装与注意事项
- 发布 Windows x64 NSIS 安装程序，需要 Windows 及 WebView2；不发布便携版 EXE 或 Android APK。安装包未签名，Windows 可能提示未知发布者。
- 加速下载在本版本才引入：从 0.2.3 升级到 0.2.4 这一次，仍是旧代码发起下载、走 GitHub 直连；加速能力从之后的版本升级开始生效。
- 镜像前缀可在 `src/config/appInfo.ts` 的 `UPDATE_DOWNLOAD_ACCELERATORS` 中调整；新增镜像域名必须同步更新 `src-tauri/src/lib.rs` 的 `validate_update_url` 白名单，否则请求会被拒绝。
- 安装前关闭旧版应用，建议先在“题库资源”导出全量备份；沿用应用标识和用户数据目录。卸载时不要选择删除应用数据。
- 本次不改动题库格式、学习数据格式和用户目录，覆盖升级沿用既有数据。
- 安装包不包含本地私人题库、图片、错题数据或开发 API 密钥。
