## 更新摘要
- 修复 Windows 桌面端无法把文件拖入程序的问题：拖拽落点不再被原生窗口拦截，整个文档转换区域都能接收文件。
- 修复运行终端起始高度不占满、日志变多后把整页撑长的问题：终端固定占满剩余空间，长日志只在终端内部滚动。
- 改善文档转换的严格程度：题目缺少答案不再导致整份题库保存失败，改为在运行终端逐题提示；缺少解析不再产生任何提示。
- 精简文档转换页面：移除页面内的转换结果 JSON 预览和提示信息，结果统一在运行终端查看。
- 移除“AI 模型配置”中关于接口地址与本地网关的说明文字。

## 详细更新
本次为 v0.2.3 补丁版本，日期：2026-10-21。构建与发布状态见本版本 GitHub Release。

### 拖拽导入
- Windows WebView 默认由原生层接管拖放，HTML5 的 `drop` 事件无法到达页面，因此文档转换区域的拖放此前完全不响应。窗口配置改为把拖放交还网页层。
- 拖拽事件从内层虚线框提升到整块文档转换区域，落点稍有偏移也能接收文件；原有的进入计数逻辑保留，避免子元素触发 `dragleave` 造成高亮闪烁或丢失投放事件。
- 新增全局 `dragover` / `drop` 拦截，防止文件拖到页面其他位置时 WebView 直接打开该文件并离开应用。

### 运行终端布局
- 终端页容器改为不滚动的纵向弹性布局，终端自身占满标题以下的全部高度；日志区独立滚动，超长内容不再撑高整个页面。
- 进入终端时自动定位到最新一条日志；只有当视图已贴近底部时才自动跟随新日志，向上翻看历史时不会被拉回底部。
- 移动端终端页改为固定高度并允许内部收缩，行为与桌面端一致。

### 文档转换与答案缺失
- 转换器本身允许空答案，此前的失败来自保存前的导入校验：任何空答案都会被判为“缺少有效答案”，导致整份题库保存失败。现在 AI 转换路径允许题目暂时没有答案，缺答案只作为提示写入运行终端，并带上题号和题干摘要，便于在题库中定位补全。
- 人工导入路径仍保持严格校验，缺答案继续拒绝导入；选项缺失、答案与选项不匹配等结构性问题在两条路径上都仍然阻断。
- 读取已保存题库时同样允许缺答案，避免出现“保存成功但打开就报错”。
- 练习页在题目确实没有答案时，不再显示空白的“参考答案”，改为提示原文未提供答案、暂不判分，而不是误报“回答错误”。
- 解析缺失不产生任何提示，也不影响保存。
- 文档转换页面移除转换完成后的题库 JSON 面板（汇总、保存位置、复制与备份按钮、JSON 文本框）、页面内提示条和 Prompt 就绪状态点；转换结果仍照常写入本机题库。

## 安装与注意事项
- 发布 Windows x64 NSIS 安装程序，需要 Windows 及 WebView2；不发布便携版 EXE 或 Android APK。安装包未签名，Windows 可能提示未知发布者。
- 拖拽开关编译进窗口配置，必须使用本版本安装包才能生效；旧版本仍会拦截拖拽。
