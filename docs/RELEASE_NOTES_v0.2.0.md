# v0.2.0 发行说明

日期：2026-10-15。状态：追加升级数据保护已完成本地验证与重新构建，尚未上传 Release；Windows 普通权限安装、升级、卸载验收仍待执行。

## 用户可见变化

### 1. 终于可以完整备份学习资料

新增“设置 → 题库资源 → 数据与备份”：一次导出题库、图片、错题本、错题记录、做题进度及显示偏好，不再只是旧版的错题本备份。恢复前有数量预览、完整性校验和覆盖确认。默认不含 AI 配置或 API Key。

恢复前自动保存快照，可单独导出；保存时保留最近错题快照。损坏数据有保护路径，恢复中途失败会尝试回滚，进程中断后会在下次启动完成回滚。

### 2. 导入前先知道是否能用

题库管理新增 JSON 导入预览，显示文件名、题数、题型分布和图片引用数量。集中报告题号、字段、错误原因与修复建议，可导出问题报告；无效 JSON、空题库、重复题号/ID、未知题型、无效选项和答案不直接保存。支持 UTF-8 BOM、中文文件名与旧题型别名。

题库列表区分文件导入、AI 转换、手动用户目录、开发目录与旧版迁移来源。首页原有导入入口同样先校验、预览后确认；刷新磁盘目录也会检查答案和 ID，不修改用户原文件。

修复启动兼容性回归：旧版 `综合题`、`综合应用题`、`SQL综合题` 没有子题时，按简答题加载并显示整题参考答案，不再误报缺失 `subQuestions` 而跳过整个题库；有子题时继续使用复合题界面。补齐 `代码应用题` 到编程题的别名。转换只发生在内存，不修改原题库、题号或 ID；新格式 `compound` / `复合题` 仍校验非空子题。另修复网页图标引用不存在文件导致的 404。

### 3. 学习过程更容易续上

练习、专项、错题保存答案、顺序、位置及复合题草稿；新增未交卷考试和背题位置恢复。页面隐藏、关闭和切回首页时尽早保存，原生端另存原子快照；已提交考试不再恢复为未提交会话。

修复多选判题时原地排序用户答案；修复考试复合题按子题数累计、导致总分超过题目总数的问题，改为整道复合题全对计 1 题。简答题不纳入自动判分分母。删除题库清理对应会话，避免文件名前缀相近时误删其他题库进度。

### 4. 桌面做题可以选择两种呈现

本次一并交付工作区已有的滚动/传统双模式。在偏好设置切换，传统模式一题一页；两种呈现共用答案、结果和草稿，切换不重开练习。保留 Markdown、LaTeX 公式、题干复制反馈及错题再练等交接改进。

滚动模式不显示“上一题 / 下一题”或底部翻页栏，保留滚动浏览、答题卡跳转及考试提交入口；传统模式保留翻页按钮。

### 5. 数据版本和保存保护

应用版本统一为 0.2.0，应用数据版本为 2。沿用旧用户目录和 v1 错题本格式，为 v0.1.5/v0.1.6 增加非破坏迁移入口。原生错题/进度/AI 配置采用临时文件、刷新、原子替换和上一份快照；保存失败明确提示，不把损坏文件当成空文件静默覆盖。

针对升级保留错题本追加保护：每个版本首次启动先自动保留升级前原生及浏览器原件，保护失败则停止启动；错题本加载完成后才写入新的学习快照，防止较新的偏好/进度快照夹带旧错题本覆盖新数据。应用内更新下载完成后再次等待保存，保存失败不启动安装、不退出应用。目标是直接覆盖升级后继续使用，不要求手动导入备份。

## 兼容性与边界

- 原有 v1 错题本 JSON 在错题本页面恢复；新全量备份在设置页恢复，二者不是同一种格式。
- v0.2 仅承诺同运行环境恢复，不承诺 Windows/Android/Web 跨端迁移。
- 不提供 AI 密钥迁移；远程图片不离线打包；单文件 JSON 导入需自己提供引用图片。
- 升级保留用户数据；卸载时不要选择清理应用数据。浏览器清理仍会删除站点数据，独立导出备份不可替代。
- 稳定题目 ID、题库内容修改后的历史关联、云同步不在本次范围。
- Chrome 浏览器自动化通过不等于 Windows 原生安装验收完成。尚未发布标签或上传资产。
- 追加升级数据保护：原生错题读取在当前文件不存在时回退检查旧版 Windows 本地/配置目录，并复制到标准应用数据目录；不会用空浏览器副本覆盖旧错题本。安装器更新流程不删除应用数据，卸载时仍不要勾选删除数据。
