# v0.2 数据保护与备份说明

## 数据盘点

| 数据 | Windows / Android 原生 | Web | 备份范围 |
| --- | --- | --- | --- |
| 磁盘题库、图片 | 正式版用户本地数据 `content/subjects`、`content/images`；桌面开发版仍使用项目 `public` | 静态站点资源，只读 | 原生备份磁盘内容；Web 将静态题库及 `/images/` 图片打包为可恢复的应用内题库 |
| 应用内导入/生成题库、图片 | WebView IndexedDB `exam-generated-banks`；有历史记录的旧题库保持原 ID，避免迁移断链 | 同名 IndexedDB | JSON、名称、原 ID、图片二进制 |
| 错题本、错题记录、蒙对标记 | 应用数据目录 `quiz-data.json`，浏览器 `wrongNotebookData_v2` 为副本 | `wrongNotebookData_v2` | 包含；保留旧版 v1 错题本导入入口 |
| 练习、错题、专项、未交卷考试、背题进度 | localStorage 即时保存；原子保存到 `learning-state.json` | localStorage | 答案、顺序、题号、子题草稿及子题结果 |
| 深色模式、桌面呈现、更新偏好、PlantUML 地址、所选题库 | localStorage，同时进入 `learning-state.json` | localStorage | 包含 |
| 题库来源 | `bankSources_v2`，并进入原生学习快照 | 同名 localStorage 键 | 文件导入、AI 转换、旧版迁移；手动/开发/只读目录按位置识别 |
| AI 配置与 API Key | 应用配置目录 `llm-config.txt`；桌面开发版配置与正式默认模板隔离 | 配置 localStorage、密钥 sessionStorage | **全部排除，不提供含密钥导出选项** |
| 恢复前快照 | IndexedDB `exam-data-snapshots` | 同名 IndexedDB | 留在本机，可单独导出；不是云备份 |

应用标识仍为 `com.exam.assistant`。Windows 原生学习记录通常在 `%APPDATA%/com.exam.assistant/`，题库通常在 `%LOCALAPPDATA%/com.exam.assistant/content/`；设置中的实际目录显示优先于示例路径。Android 的目录由系统分配，不承诺用户可直接访问。

升级读取会优先使用标准 `%APPDATA%` 数据文件；如果标准文件不存在，还会只读检查旧版可能使用的 `%LOCALAPPDATA%` 或应用配置目录，并将找到的原文件安全复制回标准目录。这个回退不会用空浏览器副本覆盖旧文件。

## 升级自动保留错题本

正常覆盖升级的要求是：**无需导出再导入，已有错题本、记录及其关联直接继续使用**。手动备份是额外保险，不是升级保留数据的替代实现。

- 保持应用标识 `com.exam.assistant`、`quiz-data.json` 和 `wrongNotebookData_v2` 不变；原生读写使用同一个 Rust 路径解析器。备用目录回退是防御性兼容，不表示已确认本次丢失由路径变化造成。
- 每个应用版本首次启动，在迁移、加载浏览器快照或挂载页面之前，自动将原生错题/学习文件及 `.bak`、相关浏览器原始记录留存在 `%APPDATA%/com.exam.assistant/upgrade-backups/<版本>/`。保留损坏原文，不包含 AI 配置；后续普通保存不轮转、也不覆盖这份升级前副本。没有成功完成保护则停止启动，不继续生成空文件。
- 等待原生错题本加载完成才允许首次学习快照落盘。恢复学习快照时，单独比较其内嵌错题本的时间，而不是以偏好设置或进度的更新时间认定错题本也更新，避免旧副本覆盖较新错题。
- 应用内更新下载前和下载完成后都等待错题本、学习记录保存完成；下载过程中的答题也进入最后一次保存。任何保存失败或数据保护状态均不启动安装器；取消安装或 UAC 后应用不主动退出。
- 上述副本用于保留升级前原件和故障排查，不是全量备份格式，也不会在每次启动自动回滚，避免恢复已经主动删除的记录。快照与原数据同盘，无法抵御磁盘损坏或明确删除整个应用数据目录。

自动化升级回归使用冻结的 v0.1.6 实际存储实现生成多错题本、错题和蒙对记录，然后用新版打开同一原生数据文件；浏览器缓存为空，无手动恢复操作。核对 ID、题库关联、当前错题本和记录内容，再新增错题并重启。另覆盖较新浏览器副本、较新原生副本、损坏文件、写入失败及安装前保存顺序。真实 Windows 覆盖安装仍必须单独验收，不能用这些测试替代。

## 数据版本和升级

- 应用版本统一为 `0.2.0`；应用数据 `schemaVersion = 2`，同时记录 `appVersion`、`savedAt`。
- v0.1.5 / v0.1.6 使用相同的应用标识和存储键。升级增加版本信封和原生进度快照，不清空旧题库或改变错题题号。
- `quiz-data.json` 保留 `version: 1` 兼容结构；新保存附带应用数据版本。旧的 v1 错题本 JSON 仍从错题本页面恢复，不能冒充全量备份。
- 浏览器版本记录显示更高数据版本时阻止降级启动；未知原生版本或损坏数据进入保护状态，不当作空数据自动覆盖，尽可能保留浏览器/原生副本并显示保护提示。
- 有历史记录的应用内题库暂不自动搬到磁盘目录，以保留旧 ID。题库改题号、排序或内容后稳定关联的完整方案仍属于 v0.3。

## 原子保存和快照

原生错题、学习快照和 AI 配置保存均先写同目录临时文件、刷新文件数据，再原子替换目标；Windows 使用带替换和写穿标记的 `MoveFileExW`，不先删除旧文件。错题与学习快照在成功覆盖前保留 `.bak` 上一份文件；AI 配置不创建历史凭据副本，并清理该配置已知的 `.bak`，避免清除密钥后仍留下本版本产生的旧密钥备份。用户自己另存的旧配置文件需要自行清理。新题库保存沿用临时文件落盘、同名自动加序号机制。

有有效原生副本时，损坏的浏览器原文先另存为 `wrongNotebookData_v2.damaged`，再恢复正常缓存。浏览器错题记录保存前保留一份 `wrongNotebookData_v2.previous`。设置中的“恢复最近错题快照”只恢复错题数据，不回退题库和练习进度。原生环境优先使用原生 `.bak`。

保存失败有明确提示；浏览器存储或磁盘写满时，不能把临时内存状态当成已经可靠保存。请及时导出独立备份。浏览器快照、IndexedDB 和原生文件都不是跨设备同步，也不能抵御整个磁盘损坏。

## 全量备份与恢复

入口：桌面“设置 → 题库资源 → 数据与备份”；移动端“设置 → 资源管理 → 题库资源”展开。

1. 导出 `biejuan-full-v2-时间.json`，包含格式标识、SHA-256 和完整载荷。API Key、AI 配置和无关站点键不进入载荷。
2. 恢复先检查格式、版本、校验和、题库、图片编码、安全路径、错题引用以及练习记录字段；确认页显示题库、图片、错题本和进度数量。
3. 明确确认后，先保留恢复前快照和精确回滚快照，再写恢复中标记。恢复会替换学习记录、偏好与应用内题库；同路径磁盘文件覆盖，额外磁盘题库保留。
4. 原生多文件恢复有持久化撤销日志。第二个文件写失败时回滚第一个文件；进程中断后，在应用初始化时重放日志。
5. 若浏览器提交失败，恢复原来的 IndexedDB 和 localStorage，并删除此次新增的原生文件；跨资源中断通过恢复标记在下次挂载应用前回滚。
6. 成功后重新加载应用，重新加载各页面和内存状态。已交卷考试会清除临时考试会话，不把旧考试重新当作未交卷恢复。

当前数据已损坏时，也允许使用有效全量备份修复。原始损坏文本单独留在保护快照；此类快照标记为排错用途，不能直接冒充有效全量备份恢复。

SHA-256 用于检测意外损坏，不是签名，也不证明备份来自可信来源。只恢复自己保管的备份。v0.2 限制为同运行环境恢复，Windows、Android、Web 跨端迁移不在本次承诺内。

## 限制

- 备份 JSON 最大 256 MB，原生文件数量与原始内容也受限制。内存不足、磁盘不足或 IndexedDB 配额不足会中止操作并保留恢复标记/原数据，不建议在接近配额时操作。
- Web 安全校验需要 HTTPS 或 localhost；普通 HTTP 局域网站点应改用安全来源。离线刷题本身不依赖 AI 或网络。
- Web 静态题库备份需能读取站点题库与 `/images/` 图片；远程图片只保留引用链接，不下载第三方资源；JSON 单文件导入不会自动读取旁边的图片目录。
- 卸载系统、浏览器清理、手动删除应用数据目录可能一起删除本机快照。升级和重装前应把备份导出到独立位置。卸载程序若询问删除应用数据，应取消该选项。
- 同一用户数据目录请勿同时启动多个应用进程或多个标签页进行恢复；恢复时停止文档转换。

## 固定 Windows 安装版验收清单

以下必须在真实普通用户环境复测，不能用自动化单元测试代替：

- [ ] 全新普通权限安装、首次启动、导入包含图片/Markdown/公式/复合题的真实大题库。
- [ ] 练习、考试、背题、专项、错题各做题并关闭/重启，核对答案、位置、子题草稿；已交卷考试不复活。
- [ ] 切换桌面滚动/传统一题一页，核对当前题、答案、错题记录和长题滚动位置。
- [ ] 导出完整备份，修改数据，恢复后核对题库、图片、错题本和进度；核对备份不含密钥。
- [ ] 注入写入失败、在恢复中途结束进程、使用损坏备份，确认旧数据保留或启动回滚。
- [ ] 中文用户目录、中文/超长文件名、只读安装目录、磁盘空间不足。
- [ ] 覆盖安装保留用户数据；卸载保留选项与重装行为符合说明。
- [ ] v0.1.6 创建至少两个题库的多个错题本、错题和蒙对记录，记录 ID、题号、题库路径及当前错题本；正常退出后直接覆盖安装新版，不导入任何备份，逐项核对，再新增错题并重启核对。
- [ ] 在隔离测试用户下分别保留和清空旧 WebView 缓存进行升级，验证原生错题文件可以独立恢复；首次启动升级保护目录保留原件，后续保存及重启不改变它。
- [ ] 更新下载失败、取消 UAC、安装失败后旧版本可继续使用。
- [ ] 更新下载期间继续答题，安装前最后一次保存包含新错题；注入写入失败时不启动安装器、不退出应用。

自动化测试覆盖相应数据算法和错误分支，但不代表以上人工项已完成。
