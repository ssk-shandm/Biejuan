## 更新摘要
- 新增本地网关模型列表的常见返回格式兼容，减少手动填写模型名称的需要。
- 修复填写完整聊天接口地址时，“获取列表”错误拼接请求路径的问题。
- 改善本地网关配置体验：自动尝试常见列表路径，提供地址示例和失败排查提示。

## 详细更新
本次为 v0.2.2 补丁版本，日期：2026-10-21。构建与发布状态见本版本 GitHub Release。

### 模型列表与地址兼容
- 填写 `/v1`、`/models` 或完整 `/chat/completions` 地址时，正确推导模型列表和聊天请求路径，不再产生 `/chat/completions/models`。
- 只填写网关基础地址且不带版本路径时，先请求 `/models`，必要时再尝试 `/v1/models`。建议仍按服务实际地址填写完整 API 基础路径，例如 `http://127.0.0.1:端口/v1`；列表探测不会自动修改已保存的聊天基础地址。
- 除标准 OpenAI `data[].id`，兼容字符串数组、`models` 数组、`data.models`，以及条目中的 `name`、`model` 字段；列表去重并排序。
- 不配置密钥获取模型列表时，不发送空的 Authorization 头；转换客户端也不再发送空 Bearer 头。服务要求认证时，仍需填写有效密钥。

### 错误提示与回归验证
- 配置页增加本地网关地址示例，模型列表错误补充请求地址、网关启动及 CORS 排查提示。
- 配置检查、lint、类型检查、132 项前端/数据测试和 16 项 Rust 测试通过，Windows 安装包构建及发布资源检查通过。
- 生产页面通过 Edge 无头浏览器连接隔离的本地模拟网关，验证主机地址回退、完整聊天地址获取列表、不同列表格式、空密钥获取列表及选中模型；无未捕获页面异常。这不是用户 Magpie 网关或原生安装器实测。
- 后续发布说明统一使用“更新摘要 / 详细更新 / 安装与注意事项”三部分，模板及发布指南已同步，新增格式回归检查；历史发行说明不改写。

## 安装与注意事项
- 发布 Windows x64 NSIS 安装程序，需要 Windows 及 WebView2；不发布便携版 EXE 或 Android APK。安装包未签名，Windows 可能提示未知发布者。
- 安装前关闭旧版应用，建议先在“题库资源”导出全量备份；沿用应用标识和用户数据目录。卸载时不要选择删除应用数据。
- 本次主要改进地址与模型列表解析，不新增原生网络代理，不绕过浏览器/WebView 的 CORS、混合内容或本地网络权限限制；必要时需在网关中允许应用访问。
- 无密钥的模型列表可以获取，但当前“测试连接”和应用内转换页面仍要求配置密钥；免认证网关的完整转换流程尚未在本版本开放。
- 尚未连接用户的 Magpie 网关实测，不能保证不同网关版本都兼容；网关还需提供 OpenAI 兼容聊天接口。未完成真实 Windows 安装、覆盖升级及卸载验收。
- 安装包不包含本地私人题库、图片、错题数据或开发 API 密钥。
